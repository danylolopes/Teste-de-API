# Testes de API - Carrefour

Projeto de testes automatizados de API utilizando Postman.

## Execução local
1. Importar a collection e o environment no Postman
2. Selecionar o environment `API-Test-Env`
3. Executar via Collection Runner

## CI
Os testes são executados via GitHub Actions utilizando Postman CLI,
gerando relatórios JUnit e HTML como artefatos da pipeline.
